# Green Beauty

App web simples (HTML único, sem dependências) da Green Beauty.

## Como publicar no GitHub Pages

1. Envie todos os arquivos deste repositório para a branch `main`.
2. Vá em **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Salve. Em ~1 minuto o site estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Arquivos

- `index.html` – o app completo (logo já embutida).
- `logo.jpg` – logo original, para referência.
- `manifest.json` e `icon-*.png`, `apple-touch-icon.png` – ícone e configuração para instalar como app.
